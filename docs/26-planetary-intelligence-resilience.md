# 阶段 26：行星级情报韧性与可信自治经济

## 完成状态

阶段 26 已完成，新增 `/api/v1/planetary-resilience` 控制面与 `/planetary-resilience` 工作台。

1. 跨组织决策证明网格支持阈值签名、依赖图、幂等交换和撤回传播。
2. 全球策略证明注册表发布模型检查、兼容性、反例、透明日志根和注册签名。
3. 后量子迁移支持经典与 PQ 混合签名、算法协商和历史证明再签名。
4. 行星数字孪生联合模拟能源、通信、物流、金融和信息空间级联。
5. Agent 宪法运行时在执行前检查不可突破边界、群体表决和人类否决。
6. 危机资源交易所支持容量、优先级配给、交付、退款和守恒结算。
7. 自治保险根据连续风险信号计算保费、限额、准备金和自动赔付。
8. 记忆跨域迁移保持用途、驻留和保留期，并生成目标包含与源端擦除证明。
9. 边缘离线消息使用签名哈希链、向量时钟和确定性恢复收敛。
10. 公共利益审计发布系统性风险、公平性、资源分配和外部性的公开承诺。

## 生产门禁

- 决策证明本身、独立签名数量和全部依赖必须同时满足信任阈值。
- 任一证明撤回必须阻断引用它的直接依赖证明。
- 身份、策略、证明和结算迁移必须同时保留经典签名与后量子签名。
- Agent 宪法违规、群体投票未达法定人数或人类否决时不得执行工具调用。
- 危机资源交易和保险赔付必须保持余额守恒，退款必须恢复可用容量。
- 记忆迁移不得改变用途、驻留区域或延长保留期。
- 离线消息恢复后必须得到与输入顺序无关的相同收敛哈希。
- 公共利益审计必须包含独立观察者证明和可重算公开承诺。
