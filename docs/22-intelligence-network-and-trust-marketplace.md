# 阶段 22：可信情报网络与生态交易规模化

1. 联邦式情报交换：跨组织共享经过策略裁剪的指标、风险信号和证据摘要，不复制受限原文。
2. 可验证数据血缘：为采集、翻译、分析、决策、行动和影响测量生成端到端 provenance graph 与签名证明。
3. 企业知识主权：细粒度用途授权、数据合同、地域边界、派生数据权利和撤回传播。
4. 模型与 Agent 供应链：模型卡、工具 SBOM、提示词签名、供应商风险、运行时证明和依赖撤回。
5. 情报产品交易市场：数据产品目录、质量 SLA、授权报价、结算分成、争议处理和退款。
6. 联邦隐私计算：安全聚合、可信执行环境适配、联合统计和跨组织隐私预算协调。
7. 决策责任图谱：把建议、审批、人工覆盖、外部执行、影响与责任人连接为不可抵赖链路。
8. 全球监管规则包：按行业与地域提供可订阅、可验证、可回滚的监管策略更新。
9. 信任与信誉体系：连接器、模板、数据产品和合作租户的质量评分、滥用举报与准入门禁。
10. 生态级韧性演练：供应商退出、区域断网、密钥泄漏、恶意数据投毒和结算中断联合演练。

## 验收门槛

- 两个隔离租户完成不泄露原文的联邦指标交换，并验证撤回传播。
- 任一行动可追溯到来源证据、模型/提示词版本、审批签名、连接器回执和影响审计。
- 市场交易在支付沙箱完成授权、交付、分账、退款和争议的端到端对账。
- 供应链证明、监管包签名、隐私预算与跨租户滥用检测进入生产门禁。

## 完成状态

- 联邦协议明确用途、允许指标、地域和最小群组；交换信封仅接受聚合指标与证据摘要，递归拒绝原文、身份、URL、令牌和密钥字段。
- 企业数据合同支持用途授权、地域边界、派生权利与撤回代次；撤回会暂停关联协议并使已发布信封不可用。
- Provenance 节点记录对象类型、版本、内容哈希和签名，边记录来源关系与证据哈希，可连接采集、模型、提示词、决策、行动、回执和影响。
- 模型、Agent、工具与提示词供应链记录 manifest、SBOM、供应商风险、签名和运行时证明；高风险或缺少证明时保持 `blocked`。
- 情报产品市场支持质量 SLA、用途许可、报价、支付授权、交付回执、分账、退款与争议状态机，幂等键防止重复订单。
- 安全聚合仅持久化总和/均值与参与方数量，标记个体输入已丢弃；TEE 查询必须携带证明后才能完成。
- 责任事件使用前向哈希链连接建议、审批、人工覆盖、执行和影响；任一事件变化会破坏后续链。
- 监管规则包按行业、地域、版本签名发布，并保留回滚目标；信誉体系结合质量、可靠性与滥用惩罚执行准入复核。
- 生态演练覆盖供应商退出、区域断网、密钥泄漏、数据投毒和结算中断，并要求遏制/恢复证据。
- `/trust-network` 提供联邦网络、情报市场、监管与生态韧性统一工作台。
