# 阶段 23：全球情报协同与持续验证

## 完成状态

阶段 23 已完成。系统新增 `/api/v1/global-coordination` 控制面和 `/global-coordination` 操作台，覆盖以下能力：

1. 联邦节点能力发现、协议版本交集协商、跨云身份指纹验证与幂等协商。
2. 数据血缘、TEE、模型签名和责任链在线证明；证明失败时状态保持 `blocked`。
3. Agent 报价约束检查、自动反报价和审批等待状态。
4. 监管包增量合并、规则冲突记录、版本激活和紧急撤回。
5. 供应商集中度、级联故障、市场操纵和数据投毒风险评分及生产门禁。
6. 合规控制期望状态持续比对、漂移明细和修复建议。
7. 情报质量证据盲审、第三方仲裁决定和信誉恢复计划。
8. 数据不出域评测，仅保存聚合指标、参与方数量和证明，明确 `sample_retained=false`。
9. 多币种汇率锁定、税务预扣、托管、付款与会计守恒校验。
10. 多租户危机室、参与方授权和命令向前哈希责任链。

## 生产门禁

- 协议版本、能力和身份信任必须同时满足，协商才可进入 `active`。
- 证明哈希、签名、责任链或 TEE 新鲜度失败时阻断执行。
- 监管冲突与超过阈值的系统性风险进入生产门禁。
- 联邦评测请求中的参与方样本不会写入数据库。
- 全球结算的预扣、托管和付款之和必须等于汇率转换金额。
- 危机命令必须由危机室参与租户签发，并链接上一条命令哈希。

运行专项门禁：

```powershell
cd backend
python scripts/stage23_release_gate.py
```
