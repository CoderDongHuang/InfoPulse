# API 契约冻结与弃用策略

阶段 29 起，`/api/v1` 为冻结的稳定契约。发布门禁使用 `docs/api-contract-v1.json` 检查路径、方法、操作 ID、响应码和弃用标记。

- 不兼容变更必须进入新的主版本路径，不能原地删除字段、收紧类型或改变成功响应语义。
- 弃用接口先设置 OpenAPI `deprecated: true`，并通过响应头公告替代接口和停止日期。
- 弃用公告期不少于 180 天；安全或监管紧急撤回需记录例外审批和迁移方案。
- 新增兼容接口后，由评审者执行 `python scripts/api_contract_check.py --update` 更新快照。
- 未经快照评审的契约变化会阻断发布。
