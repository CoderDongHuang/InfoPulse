# InfoPulse AI Intelligence Platform 产品 PRD

版本：1.0  
状态：重构基线  
产品定位：面向科技从业者、研究人员和企业团队的 AI 行业情报工作平台。

## 1. 产品目标

InfoPulse 将公共科技信息、用户私有知识和 AI 分析能力组织为连续工作流，让用户能够发现重要变化、验证原始来源、持续订阅、自动执行任务并生成可交付报告。

核心衡量指标：

- 用户首次登录 5 分钟内完成至少一个关注主题并打开一项 AI 建议。
- 事件详情中的 AI 事实陈述具备可点击引用。
- 数据源异常不阻塞其他来源同步，也不生成虚假演示数据。
- 收藏、订阅、任务、报告和通知之间可以追踪来源关系。

## 2. 用户角色

| 角色 | 主要目标 | 权限 |
| --- | --- | --- |
| 访客 | 了解产品、注册或登录 | 仅认证页面和公开健康检查 |
| 普通用户 | 研究行业、收藏、订阅、对话、生成报告 | 个人空间内完整操作 |
| 团队成员 | 使用团队知识库和共享报告 | 由团队权限决定读写范围 |
| 管理员 | 管理数据源、任务、模型、用户和费用 | 系统管理能力 |

## 3. 全局框架

### 3.1 左侧导航

分组顺序：

1. 开始工作：Workspace、Dashboard、Discover。
2. 研究分析：搜索、事件、AI 分析、数据分析。
3. AI 工作：AI Agent、任务、报告、知识库。
4. 持续关注：收藏与订阅、通知。
5. 平台管理：数据源、设置、个人中心。

行为：

- 点击菜单切换页面并保留页面筛选状态。
- 折叠按钮在桌面端切换完整/图标导航。
- 移动端导航使用抽屉，选择菜单后自动关闭。
- 有未读通知或失败任务时显示数字徽标。

### 3.2 顶部工具栏

控件：

- 全局搜索：输入关键词或自然语言，`Enter` 打开搜索结果。
- `询问 AI`：打开 AI Agent，并携带当前页面上下文。
- 同步状态：展示运行中、正常、部分异常或离线；点击进入数据源中心。
- 通知按钮：打开通知浮层；“查看全部”进入通知中心。
- 用户菜单：个人资料、主题、设置、退出登录。

### 3.3 通用弹窗

- 删除确认：显示对象名称、影响范围和不可逆提示。
- 离开未保存内容：保存并离开、放弃、继续编辑。
- 引用查看：来源标题、原文片段、时间、作者、原始链接。
- AI 使用信息：模型、数据范围、引用数、生成时间、Token 和费用。
- 权限不足：说明缺失权限并提供返回按钮，不显示无效提交操作。

## 4. 登录与注册

### 4.1 登录页 `/auth/login`

字段：邮箱/用户名、密码、记住登录。按钮：登录、忘记密码、注册、GitHub 登录、Google 登录。

流程：

1. 用户填写账号密码。
2. 前端进行必填校验，提交后按钮进入加载状态。
3. 成功后恢复目标地址；首次登录进入引导。
4. 失败在字段附近显示具体错误，连续失败触发速率限制提示。

### 4.2 注册页 `/auth/register`

字段：用户名、邮箱、密码、确认密码、同意条款。按钮：创建账户、返回登录。

弹窗/状态：条款弹窗、邮箱已存在、密码强度、验证邮件已发送。

### 4.3 首次引导 `/onboarding`

步骤：选择行业 → 添加关键词/实体 → 选择数据源 → 选择日报时间 → 完成。

按钮：上一步、下一步、跳过、完成设置。完成后创建对应收藏、订阅与任务。

## 5. Workspace `/workspace`

目标：回答“我今天应该做什么”。

区块：

- 今日关注：关注对象、新增量、热度变化、风险、未读数。
- AI 每日建议：重要度、摘要、影响、行动建议、引用和推荐原因。
- 我的收藏：最近收藏对象。
- 最近报告：草稿、生成中、完成、失败状态。
- 最近浏览：事件、搜索、实体、报告和会话。
- 今日任务：下次执行时间、状态、结果入口。

按钮：查看详情、交给 AI、收藏/取消、创建订阅、生成报告、继续编辑、标记已读、调整工作台。

“调整工作台”弹窗：拖拽排序、显示/隐藏区块、默认行业、保存、恢复默认。

空状态：未设置关注时展示“设置关注主题”；没有建议时展示数据同步状态，不填充模拟建议。

## 6. Dashboard `/dashboard`

目标：展示平台整体数据态势。

内容：今日采集量、事件数、风险事件、预警次数；热点 TOP10；最新事件；来源占比；热度/情感/事件趋势；来源健康。

按钮：时间范围、指标切换、刷新、查看事件、导出当前图表、交给 AI 解释。

筛选抽屉：时间、来源、行业、语言、地区。应用筛选后所有指标使用同一查询条件。

## 7. Discover `/discover`

频道：今日 AI、Java、机器人、开源、融资、产品、论文和自定义频道。

内容项：标题、AI 摘要、推荐原因、来源、热度变化、发布时间、所属事件。

按钮：关注频道、收藏、不感兴趣、减少类似内容、创建事件、深度分析、打开来源。

推荐反馈弹窗：不相关、已看过、质量低、来源不可信、其他。反馈影响后续推荐但不删除原始内容。

## 8. 搜索中心 `/search`

搜索框支持关键词和自然语言。热门搜索、历史搜索和已保存搜索位于搜索框下方。

筛选：时间、平台、地区、语言、情感、热度、来源、类型、原创/转载、官方/非官方。

结果列表字段：标题、摘要、来源、作者、时间、热度、情感、标签、所属事件。

按钮：搜索、清空、保存搜索、排序、切换列表/紧凑视图、收藏、加入事件、交给 AI、打开原文。

内容详情抽屉：正文、媒体、互动量、AI 摘要、实体、风险、引用和原始数据字段。

加入事件弹窗：搜索已有事件、创建新事件、相关度、设为主来源、确认。

## 9. 事件中心 `/events`

标签：热点、最新、风险、升温、已回应、已结束。

事件列表：标题、摘要、行业、状态、热度、风险、来源数、更新时间。

按钮：筛选、排序、收藏、订阅、合并、导出、打开详情。

合并事件弹窗：目标事件、保留标题、内容数量、冲突字段、确认。仅管理员/编辑角色可用。

### 9.1 事件详情 `/events/:id`

标题区：标题、状态、行业、开始/更新时间、热度、风险、置信度、来源数。

操作：收藏、订阅、交给 AI、生成报告、编辑事件、更多。

标签页：

- 概览：AI 摘要、关键进展、统计、官方回应、相关实体。
- 时间线：按时间展示来源和可信度，可切换全部/关键节点。
- 观点：观点阵营、占比、代表评论、情绪和争议点。
- 分析：原因、影响、风险、趋势预测和建议。
- 传播路径：首发、跨平台节点、关系证据、网络/时间轴/桑基图。
- 来源：原始内容列表、去重组、字段和原文链接。

编辑事件弹窗：标题、分类、状态、起止时间、风险备注。人工编辑保留审计记录。

## 10. AI 分析 `/analysis`

任务模板：摘要、观点、争议、原因、影响、风险、预测、建议、复盘、传播路径和事件比较。

输入：选择事件/内容/实体、时间范围、来源、分析深度、输出语言。

按钮：开始分析、停止、重新生成、查看引用、保存结果、生成报告、继续追问。

分析结果必须展示引用、模型、置信度、数据范围和生成时间。

## 11. 数据分析 `/analytics`

维度：平台、地域、来源、作者、时间、热词、情感、风险、实体和传播。

按钮：选择图表、配置维度/指标、筛选、保存视图、导出 PNG/CSV、AI 解读。

保存视图弹窗：名称、说明、共享范围、保存。没有数据时说明缺失来源或筛选原因。

## 12. AI Agent `/agent`

左栏：新建会话、会话搜索、固定事件、历史会话。主区：消息、引用、工具调用和结果块。

快捷任务：总结今日行业、生成日报、分析企业、比较事件、预测趋势、查询知识库。

输入栏按钮：发送、停止、添加上下文、选择知识库、上传文件、选择模型。

添加上下文弹窗：事件、搜索、收藏、报告、知识库；显示当前 Token 估算。

工具调用显示：正在搜索、读取事件、查询知识库、生成图表、创建报告或任务。产生外部通知前必须确认。

## 13. 报告中心 `/reports`

类型：日报、周报、月报、专项、事件、行业、领导简报和风险报告。

列表字段：标题、类型、状态、作者、更新时间、来源范围。

按钮：新建、继续编辑、复制、生成、下载、分享、删除。

新建报告弹窗：模板、事件/订阅/搜索范围、时间、语言、模型和生成方式。

编辑器：左侧目录、中间正文、右侧引用/AI 操作。导出 Word、PDF、Markdown、HTML。

## 14. 收藏与订阅 `/collections`

收藏标签：全部、事件、内容、实体、关键词、报告。支持文件夹、标签、备注、批量移动。

订阅标签：关键词、行业、企业、人物、产品、搜索条件。

新建订阅弹窗：对象、查询条件、来源、频率、时区、输出、通知渠道、启用状态。

按钮：编辑、暂停、恢复、立即运行、查看更新、转为任务、删除。

## 15. 任务中心 `/tasks`

任务列表：名称、类型、计划、下次执行、最近状态、成功率、费用、启用状态。

创建任务流程：选择模板 → 配置输入 → 配置计划 → 选择输出 → 选择模型 → 确认。

任务详情：配置、运行历史、日志、输出、Token/费用和关联通知。

按钮：立即运行、暂停、恢复、编辑、复制、取消运行、重试、删除。

删除弹窗说明不会删除已生成报告；取消运行弹窗说明可能产生部分费用。

## 16. 通知中心 `/notifications`

类型：预警、订阅、任务、报告、同步异常、系统。状态：未读、已读、归档。

按钮：标记已读、全部已读、筛选、归档、打开关联对象、配置通知。

同类通知按 `group_key` 聚合，可展开查看明细。

## 17. 知识库 `/knowledge`

左栏：知识库列表。中间：文件表格。右栏：预览、解析状态和检索测试。

按钮：新建知识库、上传文件、导入网页、新建文件夹、重新解析、测试检索、删除。

上传弹窗：拖放 PDF/DOCX/MD/TXT，展示格式、大小和数量限制。

导入网页弹窗：URL、抓取深度、更新频率、预览、确认。

删除知识库弹窗要求输入名称确认，并说明向量与文件一并删除。

## 18. 数据源中心 `/sources`

表格：名称、类型、方式、状态、同步计划、最后成功、数据量、错误。

按钮：启停、立即同步、测试连接、查看日志、配置、添加 RSS。

配置弹窗按来源显示 Token、查询范围、频率和限额，不回显完整密钥。

添加 RSS 弹窗：URL → 验证 → Feed 预览 → 名称/分类/频率 → 保存。

## 19. 系统设置 `/settings`

标签：AI 模型、通知、外观、语言与时区、隐私与保留、数据导出、安全。

AI 模型支持 OpenAI、DeepSeek、Claude、Gemini 和兼容 OpenAI 协议的服务。

按钮：新增供应商、测试连接、设置默认、设置降级顺序、删除密钥、保存。

敏感操作弹窗：重新验证密码、删除账户、导出数据、注销其他设备。

## 20. 关键业务流程

### 20.1 数据到建议

数据源同步 → 标准化 → 去重 → 事件聚合 → AI 分析 → 个性化排序 → Workspace/Discover 展示 → 用户反馈。

### 20.2 订阅自动化

创建订阅 → 创建/更新任务 → 到期执行 → 获取新增内容 → 生成摘要/报告 → 创建通知 → 邮件/Webhook 投递。

### 20.3 RAG 问答

上传文件 → 安全校验 → 解析 → 分段 → 向量化 → 索引 → 用户提问 → 权限过滤 → 混合检索 → 带引用回答。

### 20.4 事件报告

事件详情点击生成报告 → 选择模板 → 后台任务 → 报告草稿 → 用户编辑 → 导出/分享。

## 21. 通用状态与异常

- 加载：使用骨架或局部进度，避免遮挡整个页面。
- 空数据：解释原因并提供唯一明确的下一步。
- 部分失败：保留成功来源，列出失败来源及重试按钮。
- 权限失败：HTTP 403，不泄露对象是否存在。
- AI 失败：保留输入与来源，允许更换模型或重试。
- 离线：只允许查看已缓存页面，不显示“同步成功”。
- 删除：重要对象采用软删除；知识库文件和账户删除遵循明确保留策略。

## 22. 非功能要求

- 桌面、平板、手机关键流程可达，无横向溢出。
- 列表接口 P95 小于 800ms（不含外部同步和 AI）。
- 长任务异步执行，并能查询进度、取消和重试。
- API Key 加密保存，日志不得记录密钥和完整私有文档。
- 所有 AI 事实输出包含引用；预测和推断必须标识。
- 数据源遵守平台条款、限流和用户授权范围。
