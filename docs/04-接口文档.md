# InfoPulse API 接口文档

版本：v1  
基础路径：`/api/v1`  
格式：JSON；文件上传使用 `multipart/form-data`；流式 AI 使用 SSE。

## 1. 通用约定

### 1.1 认证

```http
Authorization: Bearer <access_token>
```

Access Token 短期有效，Refresh Token 仅用于刷新。第三方数据源 Token 不通过普通查询接口返回。

### 1.2 分页响应

```json
{
  "items": [],
  "page": 1,
  "page_size": 20,
  "total": 0,
  "has_more": false
}
```

### 1.3 错误响应

```json
{
  "error": {
    "code": "EVENT_NOT_FOUND",
    "message": "事件不存在或无权访问",
    "details": {},
    "diagnostic_id": "01J..."
  }
}
```

状态码：`400` 参数语义错误、`401` 未认证、`403` 无权限、`404` 不存在、`409` 冲突、`422` 字段校验、`429` 限流、`500` 内部错误、`502` 外部来源失败、`503` 暂不可用。

### 1.4 长任务

创建分析、报告、同步或任务运行返回 `202 Accepted`：

```json
{"job_id":"uuid","status":"queued","status_url":"/api/v1/jobs/uuid"}
```

`GET /jobs/{id}` 返回进度、状态、结果位置和错误。`POST /jobs/{id}/cancel` 请求取消。

### 1.5 时间与幂等

- 时间使用 ISO 8601 UTC。
- 创建报告、任务运行、收藏等接口支持 `Idempotency-Key`。
- 更新资源使用 `updated_at` 或 ETag 处理并发冲突。

## 2. 认证与用户

### `POST /auth/register`

请求：`username`、`email`、`password`、`accept_terms`。响应 `201` 用户公开信息和验证状态。

### `POST /auth/login`

请求：`account`、`password`、`remember_me`。响应：

```json
{"access_token":"...","refresh_token":"...","token_type":"bearer","expires_in":1800,"user":{}}
```

### `POST /auth/refresh`

请求：`refresh_token`。刷新令牌轮换，旧令牌失效。

### `POST /auth/logout`

撤销当前刷新令牌；`POST /auth/logout-all` 撤销全部设备。

### 其他

- `POST /auth/forgot-password`
- `POST /auth/reset-password`
- `POST /auth/verify-email`
- `GET /auth/oauth/{provider}/start`
- `GET /auth/oauth/{provider}/callback`
- `GET /users/me`
- `PATCH /users/me`
- `GET /users/me/sessions`
- `DELETE /users/me/sessions/{id}`
- `DELETE /users/me`

## 3. Workspace 与 Dashboard

### `GET /workspace`

参数：`date`、`timezone`。响应：

```json
{
  "date":"2026-07-28",
  "attention":[{"target":{},"new_count":21,"heat_change":32.5,"unread_count":8}],
  "recommendations":[],
  "recent_reports":[],
  "recent_views":[],
  "tasks":[],
  "source_warnings":[]
}
```

### `PATCH /workspace/layout`

请求区块顺序、可见性和默认行业。

### `GET /dashboard`

参数：`from`、`to`、`sources[]`、`industries[]`、`language`、`region`。

响应包含 `metrics`、`hot_events`、`latest_events`、`risk_events`、`trends`、`source_distribution`、`source_health`。

### `GET /dashboard/trends`

参数：通用筛选、`metric=heat|sentiment|events|content`、`interval=hour|day|week`。

## 4. Discover

### `GET /discover`

参数：`channel`、`range=day|week|month`、`language`、`page`、`page_size`。

### `GET /discover/channels`

返回系统频道和用户自定义频道。

### `POST /discover/channels/{id}/follow`

关注频道；`DELETE` 取消。

### `POST /discover/items/{id}/feedback`

请求：`feedback_type`、`reason`。类型：`not_interested/seen/low_quality/irrelevant`。

## 5. 搜索与内容

### `GET /search`

参数：

- `q`：关键词或自然语言。
- `from/to`、`sources[]`、`types[]`、`regions[]`、`languages[]`。
- `sentiments[]`、`heat_min/max`、`is_original`、`is_official`。
- `sort=relevance|newest|heat`、`page`、`page_size`。

响应项：`id`、`title`、`summary`、`source`、`author`、`published_at`、`heat`、`sentiment`、`tags`、`event`、`canonical_url`。

### `GET /contents/{id}`

返回正文、互动量、实体、AI 标注、所属事件、重复内容和原始来源字段。

### `GET /contents/{id}/comments`

参数：情绪、排序、分页。仅来源支持评论时可用。

### `POST /saved-searches`

保存查询：`name`、`query`、`filters`；提供 GET/PATCH/DELETE。

## 6. 事件

### `GET /events`

参数：`tab=hot|latest|risk|rising|responded|closed`、`status[]`、`category[]`、`risk_min`、`heat_min`、`from/to`、`sort`、分页。

### `POST /events`

请求：`title`、`category`、`content_ids[]`。用于人工创建事件。

### `GET /events/{id}`

响应：事件核心字段、AI 摘要、指标、相关实体、官方回应、关键进展和权限。

### `PATCH /events/{id}`

更新标题、类别、状态、起止时间、风险备注。需要编辑权限。

### 事件子资源

- `GET /events/{id}/timeline`
- `GET /events/{id}/viewpoints`
- `GET /events/{id}/analyses`
- `GET /events/{id}/propagation`
- `GET /events/{id}/contents`
- `GET /events/{id}/similar`
- `GET /events/{id}/entities`
- `POST /events/{id}/contents`
- `DELETE /events/{id}/contents/{content_id}`

### `POST /events/merge`

请求：`source_event_ids[]`、`target_event_id`、`field_strategy`。返回后台任务。

## 7. AI 分析

### `POST /analyses`

```json
{
  "analysis_type":"risk",
  "event_ids":["uuid"],
  "content_ids":[],
  "date_range":{"from":"...","to":"..."},
  "source_ids":[],
  "depth":"standard",
  "language":"zh-CN",
  "model_profile_id":"uuid"
}
```

返回后台任务。分析类型：`summary/viewpoints/controversies/causes/impact/risk/forecast/advice/retrospective/propagation/compare`。

### `GET /analyses/{id}`

返回 `result`、`summary`、`confidence`、`citations`、`model`、`data_scope`、`generated_at`。

### `POST /analyses/{id}/regenerate`

可指定新模型或补充指令，保留旧版本。

## 19. 安全要求

- 所有对象查询同时校验用户/团队权限。
- 文件下载使用短期签名地址。
- 上传文件进行类型、大小、压缩炸弹和恶意内容检查。
- 外部 URL 导入防止 SSRF，只允许 HTTP(S)，阻止私网和重定向到私网。
- 密钥字段写入后不可读取明文。
- Webhook 使用签名、超时、重试和目标地址验证。
- API 限流按用户、IP、来源和高成本 AI 操作分别设置。
