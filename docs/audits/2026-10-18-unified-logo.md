# R27 统一项目标志

状态：已完成。日期：2026-10-18。

浏览器原先使用内嵌卫星 emoji；public 中还残留未使用的 Vite 标志，登录页与导航栏则分别用两套 CSS 绘制。现在统一引用 `frontend/public/favicon.svg`：蓝色圆角底与白色信号柱，适合小尺寸标签页，颜色与主导航一致。

HTML favicon、登录页、顶部导航共享同一资源和版本参数 `pulse-1`，可避免继续命中旧卫星图标 URL。图标是本地 SVG，无外部字体或图片依赖。

验证：前端生产构建和 57/57 回归通过；Edge 产品验收 14/14，通过真实 HTTP 确认图标返回 200，登录页及认证后导航图像均成功解码为 64px，引用地址与 favicon 完全一致。私人配置五种视口和全部 36 路由回归通过。

浏览器可能临时保留站点旧图标；更新后重新打开标签页即可获取带版本的新地址。

CI 的开发服务器验收还发现：Vue 静态 `src` 经 Vite 转换后可能内嵌成 data URL，与 HTML favicon 的地址不同。改用显式字符串绑定，保留公共资源 URL，使开发模式与生产构建均请求同一版本的 SVG；保留地址一致性及图像解码断言，不放宽验收。

容器回归另暴露了表单测量的时序问题：路由入场动画期间，两个独立浏览器调用可能测到不同帧的整体位移。布局验收改为在同一 JavaScript 调用中读取成对控件及卡片的矩形，仍要求误差小于 1px，不通过增大容差掩盖错位。
