# R19：顶部导航、个人中心与搜索入口验收

日期：2026-10-15。本项记录交付范围与复现证据；PR 最新 head 的完整 CI 仍是合并前提，本机通过不替代云端门禁。

## 已完成

- [x] 左侧导航改为顶部导航：工作台、数据概览、发现为常用入口，其余按研究分析、协作与行动、平台与工具分组；保留原有静态目的地，管理员入口仅对管理员展示。菜单隐藏不是后端授权机制。
- [x] 右上角头像菜单提供个人中心、退出登录；支持 Enter 打开、Escape 关闭并回到触发按钮，窄屏使用右侧导航抽屉。
- [x] 移除内容/工具栏的旧侧栏偏移，采用灰白蓝主题、统一边框和克制阴影；顶部主栏 68px，工具栏桌面 56px、小屏 52px。
- [x] 新增 `/profile`：真实读取和保存用户名、邮箱、头像链接，显示账户摘要、撤销、提交中禁用、409 冲突和网络失败保留输入。刷新后从 API 重新读取验证，不用前端缓存冒充持久化。
- [x] 资料 patch 仅发送实际变更字段，trim、邮箱小写、限制新用户名包含 @；未变更的历史 @ 用户名不被顺手改写。头像仅渲染无内嵌账号密码的 HTTP(S) 链接，失败回退首字，使用 no-referrer。
- [x] Store 更新资料时校验会话 epoch，迟到响应不能覆盖退出后或已切换账户的用户信息。
- [x] 全局搜索读取路由 q，连续两次新关键词都进入实际请求。初始请求显示加载，失败明确提示并可重试，不显示成“没有匹配”；筛选来源和保存搜索独立读取，部分失败保留成功部分。

环境：Windows、Node、Python 3.10、缓存 PostgreSQL 16/Redis、隔离 API、Vite dev、Edge。脚本创建随机 fixture，无个人 `.env`、真实业务数据或付费模型调用。

| --- | --- | --- |
| `npm test` | 36/36，无跳过 | 真实函数、导航集合、资料 patch、epoch、搜索失败恢复 |
| `npm run build` | 类型、生产构建和预算通过 | 静态入口 JS raw 505160 / gzip 174180，CSS raw 133805 字节 |
| `scripts.product_smoke` | 12/12 | 真实 UI/API/数据库、WebSocket、登录撤销及原有业务回归 |

| 响应式专项 | 1024/768/390/320px 通过 | 工作台与个人中心无持续页面横向溢出，移动导航可到达 |

本次新增 7 项前端回归：5 项导航/资料与 2 项搜索状态。浏览器新增一组完整外壳/资料链路，旧 11 组继续执行。新组验证真实其他账户邮箱冲突返回 409，断网保存保留输入，挂起 PUT 期间字段和按钮禁用、请求仅一次；放行后独立 GET 和 reload 均读取到新用户名。退出后仍检查旧令牌服务端失效，并用修改后的用户名重新登录。

键盘测试曾暴露 Escape 关闭后菜单仍保持可见，现显式关闭实例并恢复触发器焦点。布局检查曾在抽屉/路由退出动画中读取瞬时 scrollWidth，现等待 5 秒内恢复合理宽度，超时输出实际溢出元素，不忽略持续溢出。文档截图快进有限 CSS 动画到终态，交互测试仍保留动画；避免把过渡半透明帧作为界面成品。已目视检查桌面工作台、资料页、头像菜单和移动页面。

## 尚未完成与优化顺序

1. 全站旧业务页硬编码颜色、密集布局与重复请求状态继续按领域迁移；本次统一外壳不是每个页面全面重写。
2. 搜索详情、保存搜索、创建事件等其他按钮的取消/超时/并发响应顺序尚需单独测试；本次证明搜索入口与读取失败，不声称所有搜索操作完成。
3. 头像文件上传、裁剪、受信图片代理不在本项内。公开 URL 由浏览器直接请求目标，no-referrer 不能隐藏客户端 IP；用户应使用自己信任的图片源。
4. 账户删除跨存储一致性与 legal hold 尚在设计验收，本页没有不可靠的删除入口。外部提供商、媒体/行动/编排 worker 中断恢复及跨域固定 fixture 仍按路线图推进。
5. 菜单和焦点基础键盘检查已做，不等于完整 WCAG 审计；全站屏幕阅读器、对比度量化、暗色与多语言继续保留为目标。

R18 与本项分开提交和验收，不自动合并其他依赖升级 PR。开源定位继续是可本地使用的 v0.x 开发者预览。
