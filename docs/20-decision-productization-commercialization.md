# 阶段 20：智能决策产品化与商业化

## 已交付

- 行动模板市场采用包与不可变版本模型；回滚会创建新版本并保留目标版本、校验和与变更说明。
- Slack、Teams、飞书、钉钉连接器通过已审批安装执行真实 HTTPS webhook，具备幂等键、套餐门禁、回执状态与脱敏错误。
- 审批流以节点/边图保存并校验引用完整性，可配置高风险、预算超限和外部执行触发器。
- 指标采集器与归因审计分离，结论默认是 `correlation_only`，保留方法、假设、证据与置信度。
- 企业成本报表按周期与功能分摊；SLA 策略支持目标、预警和多级升级步骤。
- 匿名基准发布强制 `sample_size >= k_anonymity >= 5`。
- 套餐权益、功能开关、月度用量和成本计量在执行前门禁，超限返回明确的 402/429。
- `/commercial-operations` 提供管理员运营工作台，覆盖总览、模板版本、审批编排、SLA 和套餐限制。

## 生产门禁

在 `backend` 目录运行：

```powershell
python scripts/stage20_release_gate.py
```

门禁依次检查 Python 编译、Alembic 单头、阶段 18–20 回归、全量后端测试和前端生产构建。任何步骤失败都会返回非零退出码。

## 安全边界

连接器只允许四个受支持 provider 和已审批、未撤销、同租户的安装；不跟随重定向，不回显 webhook 或凭据。跨租户资源始终按 `organization_id` 查询。匿名基准不输出租户成员明细，影响归因不得把相关性表述为已证实因果。
