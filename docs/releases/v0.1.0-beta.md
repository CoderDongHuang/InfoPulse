# InfoPulse v0.1.0-beta

Status: draft beta release for local self-hosting and learning.

## Included

- Four-source public information path (Hacker News, GitHub, DEV Community and arXiv) with source health and graceful upstream failure handling.
- Account-scoped workspace, search, citations, rule-based no-model summaries and Agent evidence summaries.
- Explicit capability matrix and external dependency boundaries for LLM, SMTP, S3, SSO/SCIM and social-source credentials.
- Frontend orchestration and Agent state extracted into composables for focused testing and follow-up component work.
- Community issue/PR templates, CODEOWNERS and a reproducible ten-minute quickstart record.

## Known limits

- This is not a production or public-internet deployment guarantee. Real provider credentials, backups, observability, Kubernetes and long-running availability still require separate validation.
- Anonymous upstream APIs can rate-limit or change format. A source failure is shown as unavailable; the application does not fabricate articles.
- No LLM, SMTP or S3 credential is bundled. Agent and daily summaries use deterministic evidence fallbacks where implemented.
