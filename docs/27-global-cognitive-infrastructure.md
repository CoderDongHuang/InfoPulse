# 阶段 27：全球认知基础设施与长期自治治理

## 完成状态

阶段 27 已完成，新增 `/api/v1/cognitive-infrastructure` 控制面与 `/cognitive-infrastructure` 工作台。

1. 统一决策、策略、记忆、资源和审计证明格式，通过三种独立实现认证。
2. Agent 宪法升级支持影响模拟、法定投票、延迟生效、回滚和不可削弱条款。
3. 后量子透明档案使用向前链接根、时间戳见证和历史根再签名。
4. 公共情报信号记录开放指标、来源多样性、用途边界和公开承诺。
5. 认知安全中心检测证据循环、来源同质化、虚假共识和叙事操纵。
6. 自治清算支持多资产净额、流动性缓冲、压力测试和系统性熔断。
7. 危机资源配给综合紧迫度、脆弱性、公共利益与历史份额并生成解释证明。
8. 长期情景支持十年以上技术、气候、人口、监管和供应链风险路径。
9. 跨世代承诺审计跟踪长期进展、成本转移、生态外部性和未来受益群体。
10. 主权自托管栈验证可复现构建、硬件信任根、离线核心能力和安全升级。

## 生产门禁

- 证明认证必须至少覆盖三个不同实现、统一格式、全部测试向量和撤回向量。
- 宪法升级不得削弱固化条款，且必须通过影响模拟、法定投票和回滚测试。
- 认知安全发现证据循环、来源集中、虚假共识或叙事操纵时阻断发布。
- 多资产清算必须逐资产守恒；压力缓冲不足时必须打开系统熔断。
- 公平配给总量不得超过可用容量，并提供因素、分数和签名解释证明。
- 长期情景和跨世代审计必须支持确定性重放和公开承诺验证。
- 主权栈仅在构建产物可复现、硬件根可信且离线核心能力齐全时通过。
