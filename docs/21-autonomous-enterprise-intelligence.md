# 阶段 21：自治型企业情报与合规规模化

1. 连接器 OAuth 生命周期与密钥托管：支持轮换、撤销、健康探测、区域化出口和企业代理。
2. 审批流运行时：并行会签、条件分支、委托、超时升级、补偿事务与可验证电子签名。
3. 因果评估实验平台：对照组、前后窗口、差分法、混杂因素登记和统计功效检查。
4. 实时 FinOps：预算预测、异常成本检测、单位经济性、承诺用量和跨部门 chargeback。
5. 套餐商业闭环：试用、升级、降级、欠费、税务发票、信用额度和支付服务商对账。
6. 匿名基准隐私增强：差分隐私预算、最小群组策略、查询审计和反推攻击检测。
7. 策略即代码：SLA、审批、数据驻留和模型使用政策的版本化、仿真与灰度发布。
8. 多区域高可用：数据分区、灾备演练、RPO/RTO 证据和租户级故障隔离。
9. 合规证据自动化：SOC 2 / ISO 27001 控制映射、证据采集、例外管理和审计包导出。
10. 自治决策安全评测：红队场景、连接器沙箱、权限漂移检测、回滚演练和上线评分卡。

验收门槛：真实支付与 OAuth 沙箱完成端到端验证；审批运行时具备补偿与重放保证；隐私预算、RPO/RTO、策略灰度和审计证据均进入自动生产门禁。

## 完成状态

- OAuth/连接器凭据采用租约和外部密钥引用，支持轮换、撤销、到期健康检查、区域与出口策略；API 不返回密钥引用。
- 审批运行时支持幂等启动、并行节点、委托、可验证 SHA-256 签名链、拒绝后的补偿调度和重放。
- 因果实验保存处理组、对照组、观察窗口、混杂因素、功效与差分法效应；功效不足明确标记 `underpowered`。
- 财务账本支持部门 chargeback、成本预测、异常检测、单位经济性、发票/税额及支付提供商对账。
- 差分隐私预算在事务锁内扣减 epsilon，并对小群组、重复切片攻击和预算耗尽执行前置阻断。
- 策略即代码具备不可变版本、测试仿真、校验和、灰度比例和未通过禁止发布规则。
- 灾备演练同时校验实际 RPO、RTO 与租户隔离；合规域覆盖 SOC 2 / ISO 27001 控制、证据、例外和带校验和审计包。
- 自治安全评测要求评分至少 80、无权限漂移且完成回滚验证，任一缺失都会保持 `blocked`。
- `/autonomy` 提供策略、隐私、韧性、安全和 FinOps 统一控制台。

## 生产门禁

```powershell
cd backend
python scripts/stage21_release_gate.py
```

真实支付和 OAuth 凭据仍必须由部署环境的沙箱/密钥管理器提供，仓库不会保存供应商密钥。门禁通过适配器契约和持久化证据验证集成，不伪造外部供应商成功回执。
