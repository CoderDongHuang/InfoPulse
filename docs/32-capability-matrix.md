## 默认拒绝与空配置

2026-10-19 补充：私人配置提供千问北京/新加坡的文本、视觉和语音预设，语音采用独立的 `qwen_asr` 协议；兼容旧 `openai` 默认值，不需要数据库迁移。千问 ASR 返回文字但不提供时间定位，保留空时间戳。41 项后端专项和 59 项前端测试通过，四个公开源联网同步各获取 30 条；模型 SDK 合约使用 MockTransport，未使用真实百炼密钥，不代表模型质量、免费额度或账号权限已验收。详情见 [本次记录](./audits/2026-10-19-qwen-and-public-connectivity.md)。

`python -m scripts.init_local` 生成本机随机密钥，关闭 browser crawler/media worker；不会覆盖已有配置。真实 LLM、SMTP、S3 和身份提供商凭据保持为空。空配置是明确的能力边界，不是需要编造“填完整”的参数。

没有 LLM 的工作流 agent 失败且不记虚假成功成本；未登记工具执行器失败；未批准 connector、工作区不符、目标变更或内网地址被拒绝；手动行动等待人工回执。敏感指标未配置 token 时不可公开读取。

`scripts.public_server` 是独立公众使用入口：启用真实资讯同步与媒体 worker，媒体仅处理用户提交的任务，使用该任务所有者在私人配置中保存的服务。视觉、转写和邮件没有凭据时不会凭空可用。当前 API 契约为 357 个路径；历史审计数字保留其原日期与验证语境。

## 技术成功与业务成功

```text
创建记录 != 入队成功 != 被 worker 认领 != 远端确认 != 业务目标完成
```

Outbox 与 provider acknowledgement 只证明已实现的技术链路。即使消息送达，也不能自动宣称受众阅读、决策有效或影响改善。任何 UI、博客、API 使用说明均应遵守这一边界。

旧阶段文档包含设计愿景；与本文冲突时，以当前源码、[修复验收报告](./audits/2026-10-09-remediation.md) 和运行证据为准。正式稳定版需要额外威胁模型、性能、恢复、外部提供商和兼容性验收。
