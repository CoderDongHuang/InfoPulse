## 生产门禁

- `n >= 3f + 1` 且至少 `2f + 1` 个有效签名才能提交证明状态。
- 跨组织行动必须获得所有参与宪法许可，且不得削弱固化条款。
- 公共信号至少完成三个区域的一致因果复现才可进入全局决策。
- 公共国库和反共识市场必须保持会计守恒。
- 配给申诉必须可重放原始解释证明，并保留补偿责任记录。
- 文明安全阀必须达到多方阈值并通过离线降级及受控恢复演练。
