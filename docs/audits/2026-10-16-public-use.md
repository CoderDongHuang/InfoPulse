## R21：无需密钥的真实公开数据主链

### 完成项与设计

- [x] API 内嵌与独立 `sources` worker 自动检查到期来源。轮询默认 30 秒；HN/GitHub 30 分钟、DEV 60 分钟、arXiv 120 分钟。每源独立事务，故障不阻断后续来源，支持显式关闭。
- [x] 内置来源原子登记，已有配置不覆盖；外部请求在写锁之前完成，避免 SQLite 长时间阻塞注册、收藏和任务。入库使用 `last_sync_at` CAS，仅一个有效快照能写入；不是保证只发生一次网络请求。
- [x] 单源总采集预算默认 60 秒；失败落 `SyncRun` 和真实错误。批次内容使用 savepoint，非法条目导致整批内容回滚，失败记录保留，不把部分新增统计为成功。Python 3.10 使用 `asyncio.TimeoutError`。
- [x] GitHub 初次真实请求出现本机 CA 信任错误；官方采集器使用操作系统信任与 certifi 公共根的并集，保留证书与主机名校验，复测通过。未使用 `verify=False`。
- [x] 发现页默认「全部 / 本周」，未提供发布时间的内容以抓取时间参与筛选，但界面仍明确标注来源未提供日期；论文和仓库按内容类型识别。候选限制 500，分页展示 30 条。工作台使用相同公开内容推荐。
- [x] 来源普通用户只读；管理操作仍由服务端管理员鉴权。来源停用仅停止后续采集，历史内容仍可检索。读取失败、空结果、日志失败分别展示，可重试；响应乱序不覆盖新频道，收藏请求防重复提交。
- [x] HN 上游 HTML 摘要转为纯文本，原始 payload 保留；SQLite 丢失的来源/同步记录 UTC 时区恢复后序列化，避免浏览器误解为本地时间。
- [x] `scripts.public_server` 使用专用 `.public-local` 持久化目录、唯一随机密钥、自动迁移和 loopback 绑定，不读取个人 `.env`。提供已有账号管理员授权和单次真实采集维护命令。
- [x] 正常数据环境与审计环境隔离；CI、fixture 产品环境关闭真实源自动采集，避免测试文章与正常使用数据混杂。

### 后续优化

1. 上游错误按证书/超时/限流/解析分类，遵循 Retry-After、指数退避和源级熔断；目前失败按原周期重试。
2. PostgreSQL 跨进程采集竞争与中断恢复矩阵；当前 CAS 在两种方言实现，文件 SQLite 竞争有专项，不能扩大为所有部署恢复保证。
3. 检索候选下推、全文索引/游标分页和大数据量性能；目前发现页只处理最近 500 个候选。
4. RSS 实站兼容矩阵、跨源 URL 去重、语言/标签质量及源授权政策；已有 RSS 安全与格式测试不代替全部实站验证。
5. 可选 LLM、SMTP、身份/消息提供商使用真实测试账号逐个验收；实验模块继续隔离，其他未勾选路线不因此关闭。

## 使用范围

本轮按用户选择先完成无需密钥的公开数据主链。真实外部模型、SMTP、身份提供商等未配置项不应标记为已实测。页面巡检与模块回归不等于每个外部平台的业务验收；公众可自行拉取本地使用，不意味着已部署公网或承诺稳定 v1。
