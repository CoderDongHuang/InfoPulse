# InfoPulse UI 设计规范

版本：1.0  
设计方向：AI 分析师工作台，而非传统大屏 BI。

## 1. 设计原则

- 结论优先：页面先呈现“发生了什么、为什么重要、下一步是什么”。
- 证据可见：AI 内容附近必须能查看引用和数据范围。
- 工作连续：事件、搜索、报告和 AI 会话可以携带上下文互相跳转。
- 信息密度适中：业务列表紧凑，分析内容留出阅读空间。
- 状态真实：加载、失败、部分数据和模型降级必须明确表达。
- 克制科技感：依靠排版、信息结构和交互建立专业感，不使用装饰光球和大面积渐变。

- 主色不用于大面积背景。
- 风险颜色只表达状态，不作为模块主题色。
- 图表颜色使用蓝、青、绿、琥珀、红、灰的离散序列，保证色盲可辨。
- 文字与背景对比度满足 WCAG AA。

### 2.2 字体

- 中文：`HarmonyOS Sans SC`, `MiSans`, `PingFang SC`, `Microsoft YaHei`。
- 拉丁与数字：`Inter`, `Segoe UI Variable`。
- 等宽：`JetBrains Mono`, `Cascadia Code`, `Consolas`。
- 不依赖必须联网下载的字体；优先系统字体回退。

字号：

| Token | 尺寸/行高 | 用途 |
| --- | --- | --- |
| Display | 32/40 | 页面核心标题，仅一处 |
| H1 | 26/34 | 页面标题 |
| H2 | 20/28 | 区块标题 |
| H3 | 16/24 | 面板、弹窗标题 |
| Body | 14/22 | 正文 |
| Small | 12/18 | 元数据、辅助说明 |
| Code | 12/18 | ID、接口、时间戳 |

字重使用 400、500、600、700；字距固定为 0。

### 2.3 间距与尺寸

- 基础单位：4px。
- 间距序列：4、8、12、16、20、24、32、40、48、64。
- 左侧导航展开 220px，折叠 72px。
- 顶部栏 56px。
- 主内容最大宽度 1440px；数据表可以占满剩余空间。
- 图标按钮 32/36/40px，普通按钮高度 36/40px。
- 输入框默认 40px，搜索主输入框 48px。
- 触控目标最小 44px。

### 2.4 圆角与阴影

- 小控件：4px。
- 输入框、按钮、面板：6px。
- 弹窗、抽屉、重复内容卡片：8px。
- 不使用 12-16px 的大面积胶囊化卡片。
- 默认面板以边框分隔，阴影只用于弹窗、浮层和拖拽状态。
- 弹窗阴影：`0 20px 50px rgba(15, 23, 42, 0.18)`。

## 3. 布局规范

- 页面由侧栏、顶部栏和内容区构成。
- 页面标题区包含标题、简短说明、主要操作；高度随内容而定，不做大 Hero。
- 页面区块使用无框布局或全宽分隔；卡片仅用于独立重复对象。
- 禁止卡片嵌套卡片。
- 桌面双栏比例优先 `minmax(0, 1fr) 320px`。
- 低于 1024px 折叠侧栏；低于 768px 使用顶部栏与抽屉。
- 移动端表格切换为字段列表或横向滚动工具区，不压缩到不可读。

## 4. 导航

### 4.1 侧栏

- 图标使用 Element Plus 已有图标或 Lucide，风格保持一致。
- 当前项使用浅色背景、主色文字和左侧 3px 指示条。
- 分组标题 11px，菜单文字 13px。
- 徽标只显示未读/异常数量，超过 99 显示 `99+`。
- 折叠时保留 Tooltip，不显示截断文字。

### 4.2 面包屑与标签页

- 页面层级超过两级时使用面包屑。
- 事件详情标签页固定在标题下方，滚动时可吸顶。
- 标签页切换不改变事件 ID，保留各标签滚动位置。

## 5. 按钮

| 类型 | 用途 | 示例 |
| --- | --- | --- |
| Primary | 每个区域唯一主要动作 | 开始分析、保存 |
| Secondary | 次要命令 | 生成报告、测试连接 |
| Ghost | 工具和列表行操作 | 筛选、刷新 |
| Danger | 破坏性动作 | 删除、撤销任务 |
| Icon | 熟悉的工具动作 | 收藏、下载、关闭 |

规则：

- 图标按钮必须有 `title`/Tooltip 和可访问名称。
- 删除按钮不与保存按钮相邻，避免误触。
- 加载时保持按钮宽度，图标变为 Spinner，文字不跳动。
- Disabled 状态保留可读对比度，并通过 Tooltip 说明原因。
- 一组按钮最多一个 Primary。

## 6. 表单

- 标签位于字段上方；必填使用文字说明或星号。
- 错误显示在字段下方，不能只用 Toast。
- 帮助文本与错误占用稳定空间，减少布局跳动。
- 密钥字段默认隐藏，只显示末四位。
- 数字使用输入框/步进器；范围使用双端滑块；枚举使用下拉菜单。
- 二元设置使用 Switch；多选使用 Checkbox；视图模式使用 Segmented Control。
- 保存成功可使用短 Toast；保存失败保留用户输入。

## 7. 搜索与筛选

- 主搜索提供清除、历史、语法提示和快捷键。
- 已应用筛选显示为可删除标签，并提供“全部清除”。
- 筛选抽屉底部固定“重置”和“应用”。
- 搜索过程中显示局部加载；旧结果可保留并降低透明度。
- 无结果区提供检查拼写、减少筛选和创建订阅三种行动。

## 8. 表格与列表

- 表头吸顶，行高 48-64px。
- 数字右对齐，文本左对齐，状态使用点+文字而非只靠颜色。
- 行操作默认显示主要动作，其余放入更多菜单。
- 支持分页、每页数量、总数和当前范围。
- 批量操作仅在选中后出现，并显示已选数量。
- 骨架行与真实行尺寸一致。

## 9. 卡片

- 只用于事件、建议、Discover 内容等重复对象。
- 卡片包含明确标题、状态、摘要、元数据和一个主要动作。
- 整卡可点击时内部按钮必须阻止冒泡并保持键盘可达。
- 卡片最小高度固定或由统一网格约束，加载内容不导致网格跳动。

## 10. 弹窗、抽屉和浮层

- 确认类弹窗 440-520px；复杂配置使用 640-760px 或抽屉。
- 弹窗标题说明对象和动作，底部右侧为取消与确认。
- 危险确认按钮使用具体动词，如“删除知识库”，不写“确定”。
- 详情预览优先抽屉，避免打断列表上下文。
- 点击遮罩只关闭无未保存内容的普通浮层。
- `Esc` 关闭前遵循未保存确认流程。

## 11. 状态反馈

### 11.1 加载

- 首屏使用骨架；按钮操作使用局部 Spinner；长任务显示步骤和进度。
- 超过 10 秒显示后台运行说明和离开页面选项。

### 11.2 空状态

- 包含事实描述和一个主要动作。
- 不使用功能宣传或操作教程文本。
- 示例：“还没有订阅” + “新建订阅”。

### 11.3 错误与部分失败

- 页面错误提供错误摘要、重试和诊断 ID。
- 部分来源失败时仍展示成功数据，并列出失败来源。
- 网络 Toast 不重复弹出；持续离线改为顶部状态条。

## 12. AI 内容规范

- AI 输出块顶部显示 `AI 生成`、模型、时间和数据范围。
- 事实后使用引用编号，点击打开引用浮层。
- 推断使用“分析认为”，预测使用“预计/可能”，禁止伪装为确定事实。
- 置信度显示数值与文字级别，并说明影响因素。
- 提供有用、无用、问题反馈、复制、重新生成和继续追问。
- 流式输出不能导致页面不断横向或纵向跳动。

## 13. 图表规范

- 每张图有标题、指标定义、时间范围、数据源和更新时间。
- Tooltip 显示完整值与单位。
- 不使用 3D 图表、仪表盘堆叠和装饰性动画。
- 折线最多 5 条；更多系列使用筛选。
- 饼图类别不超过 6 个，其他合并为“其他”。
- 地图、传播图和知识图谱提供表格替代视图。

## 14. 动效

- 常规过渡 160-220ms，页面切换不超过 240ms。
- 缓动 `cubic-bezier(0.2, 0.7, 0.2, 1)`。
- 仅为状态变化、层级切换和操作反馈添加动画。
- 禁止无限扫描线、无意义脉冲和背景装饰动画。
- 遵循 `prefers-reduced-motion`，关闭非必要动画。

## 15. 响应式断点

| 断点 | 行为 |
| --- | --- |
| `>= 1280px` | 完整侧栏，多栏工作区 |
| `1024-1279px` | 可折叠侧栏，压缩辅助栏 |
| `768-1023px` | 图标侧栏或抽屉，双栏改主次堆叠 |
| `< 768px` | 顶部导航，单列，底部关键操作可固定 |

## 16. 无障碍

- 所有交互支持键盘和清晰焦点环。
- 图标按钮提供可访问名称。
- 弹窗打开后焦点进入，关闭后返回触发元素。
- 状态不只依赖颜色表达。
- 图表提供数据表或摘要。
- 表单错误与字段通过 ARIA 关联。

## 17. 推荐组件清单

`AppShell`、`SideNavigation`、`TopToolbar`、`PageHeader`、`GlobalSearch`、`FilterPanel`、`DataTable`、`StatusBadge`、`Metric`、`EventListItem`、`RecommendationCard`、`CitationPopover`、`AiOutput`、`TaskProgress`、`EmptyState`、`ErrorState`、`ConfirmDialog`、`SourceHealth`、`NotificationPanel`。
