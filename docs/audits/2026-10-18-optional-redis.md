# R25：Redis 可选启动失败后的连接池状态

状态：实现及本机专项验收完成。日期：2026-10-18。

在无需 Redis 的本地入口中，启动会容忍 Redis 不可用，但旧实现先把客户端写入全局变量再执行 `ping()`。连接失败后，协作 WebSocket 仍读到一个非空的失效连接池，后续调用报错。

修复为先创建候选客户端、完成探测，再发布全局引用；探测失败或取消时关闭候选池并传播异常，由原有启动层决定降级。可选消费者继续看到 `None`。没有把 Redis 依赖服务伪装成可用。

- [x] `tests.test_redis_startup`：失败释放连接池、不发布失效实例；成功探测前不可见、完成后才发布。2/2 通过。
- [x] 无 Redis 的隔离 Edge 产品验收包含协作 WebSocket 握手和持久化链路，通过。
