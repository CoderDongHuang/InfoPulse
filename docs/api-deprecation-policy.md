# API 契约冻结与弃用策略

`/api/v1` 是当前版本路径，项目仍为开发者预览，不代表已经完成稳定 v1 认证。2026-10-09 起，`docs/api-contract-v1.json` 门禁覆盖路径、方法、操作 ID、参数、认证、请求体、完整请求/响应 schema、响应码和弃用标记。当前快照为 354 条路径。

门禁是严格快照一致性检查，不是自动语义兼容性证明。兼容性新增也可能触发差异，需要评审后更新快照；不能为了通过 CI 无条件重生成。回归测试覆盖字段删除和类型变化等原先漏检的情况。

- 不兼容变更必须进入新的主版本路径，不能原地删除字段、收紧类型或改变成功响应语义。
- 弃用接口先设置 OpenAPI `deprecated: true`，并通过响应头公告替代接口和停止日期。
- 弃用公告期不少于 180 天；安全或监管紧急撤回需记录例外审批和迁移方案。
- 新增兼容接口后，由评审者执行 `python scripts/api_contract_check.py --update` 更新快照。
- 未经快照评审的契约变化会阻断发布。

## 本次安全例外与迁移

- 访问令牌现在必须携带有效服务端 `sid`，旧令牌失效；refresh 单次消费，退出会撤销会话。
- 热搜生成必须认证；全局数据源写操作要求系统管理员，普通用户得到 403。
- 连接器目标必须与已批准安装一致，拒绝内网、非 HTTPS、非标准端口和 POST 重定向。
- 未匹配条件或有歧义的工作流不再隐式进入首个分支；图校验失败返回 422，缺模型/执行器明确失败。
- `queued` 不代表工具或行动完成；等待 dispatch、人工回执和 `unknown` 都是有意义的状态。

这些变更修正危险或虚假的旧行为，属于预览版安全收敛例外。升级先备份、迁移到 `20261009_0033`、重新登录，再检查旧工作流与安装配置。正式 v1 前需完成兼容性测试、SDK 类型同步和支持周期评审。
