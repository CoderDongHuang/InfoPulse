# 阶段 25：可证明自治与全球连续智能

## 完成状态

阶段 25 已完成，新增 `/api/v1/provable-autonomy` 控制面与 `/provable-autonomy` 工作台。

1. 自治决策证明编译器连接目标、约束、证据、策略和结果，并支持独立签名验证。
2. 策略模型检查识别职责冲突、死锁、非法状态和越权路径，输出确定性最小反例。
3. 三区主动运行支持向量时钟、确定性冲突收敛、健康区域故障切换和恢复点哈希。
4. 全球监管分裂模式按区域裁剪产品能力，只保留合法域内数据路径。
5. 长期记忆执行用途、保留期、污染隔离和密码学遗忘证明。
6. Agent 群体执行规模、委托深度、工具授权、预算和通信串谋硬限制。
7. 预测市场支持抵押加权概率、集中度反操纵、Brier 评分和资金守恒结算。
8. 灾难最小内核验证离线身份、策略、审计、告警和人工接管能力。
9. 绿色算力调度在数据驻留与 SLA 内选择最低碳窗口并生成资源证明。
10. 跨生态责任结算依据责任链和仲裁结果计算赔付、追偿、准备金与责任分摊。

## 生产门禁

- 高风险操作只有在决策证明完整、约束满足且签名可重算时才能进入 `executable`。
- 模型检查发现职责冲突、死锁或越权路径时不得发布策略。
- 多区域合并至少包含三个不同区域，且必须选择健康副本作为活动区域。
- 记忆污染分数超过阈值必须隔离；遗忘操作必须生成不可混淆的擦除证明。
- 群体 Agent 任一硬限制失败或串谋风险超过阈值时保持 `blocked`。
- 预测市场集中度超过阈值时阻断交易；结算付款总额必须等于流动性池。
- 灾难内核和绿色调度不能满足身份、接管、驻留或 SLA 约束时保持阻断。
- 赔付与准备金之和必须等于损失与追偿之和，责任权重必须合计为 1。
